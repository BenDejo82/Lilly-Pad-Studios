Simulation & safety notes
Opened from GitHub or as a file, Lilly Pad Studios is a simulation and sends nothing to real lights. Opened from the LPS Bridge, it sends Art-Net to the node, with a calm-white failsafe if the app is lost. The stage preview shows strobes slowed down so it's safe to watch; real strobing is limited by Max strobe. Save Project uses this browser's storage; Export JSON makes a portable backup file. Use real fixtures only with verified profiles (see PATCH → DMX Output Monitor).
